# `data/` — cached Gemini results (committed) and media (not)

Only `cache/` is in git. Everything else here is generated locally or published to GCS.

| Path | In git? | What |
|---|---|---|
| `cache/` | **yes** | Every Gemini call the pipeline makes is content-hashed and cached here — take analysis JSON, DPR reports (`cache/reports/`) and the spoken-report audio (`cache/tts/`). This is why `ingest/run_all.sh` replays end to end for **$0** and why a cold Daily Progress Report on the hosted service answers in well under a second. Delete a file to force a re-analysis. |
| `clips/` | no | ~24 day-12 dailies cut by `ingest/clips.py`. Served from the public GCS bucket in the deployed app — see [`../deploy/gcs/publish_clips.sh`](../deploy/gcs/publish_clips.sh). |
| `thumbs/` | no | Poster frames for those clips. Also published to GCS, and baked into the Cloud Run image. |
| `footage/` | no | Source footage: *Tears of Steel* © Blender Foundation, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Never committed — download it yourself, see [`../ingest/README.md`](../ingest/README.md). |
| `seed_export/` | no | Intermediate JSON handed to `ingest/load.py`. Regenerated by the pipeline. |
| `video/` | no | Renders and scratch output for the trailer, owned by [`../video/`](../video). |

The rule in [`.gitignore`](../.gitignore): `data/*` is ignored, `data/cache/**` is un-ignored.
Media is large and re-derivable; Gemini results are small and cost money, so they ship.
